# Exotic Properties — Cinematic Website Demo

A responsive, single-page luxury real-estate website concept designed for GitHub Pages.

## Included
- Cinematic animated loading screen
- Black and gold luxury visual system
- Responsive navigation with section tabs
- Interactive 3D-inspired architectural hero artwork (CSS, no 3D model required)
- Kinetic ticker, scroll reveal animations, pointer-reactive hero
- About, services, property showcase, video placeholder, contact form
- Instagram and Facebook links
- Responsive mobile navigation and reduced-motion support

## Logo asset
Place the client's logo file named `exotic.png` inside the `assets/` folder (`assets/exotic.png`). The header, footer and loading screen are configured to use that image.

## Run locally
Open `index.html` in a browser. For a more reliable local preview, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `exotic-properties-demo`.
2. Upload the **contents** of this folder to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear in the same section.
